## Operador Logístico

Aplicación en Java para registrar envíos terrestres, aéreos y marítimos y calcular su costo.

## Estructura de carpetas

El proyecto contiene la carpeta `src`, que incluye:

- `controladores`
- `fabricas`
- `iconos`
- `modelos`
- `principal`
- `servicios`
- `vistas`
